# Milestone v1.0 Requirements

## Machine Learning
- [ ] **ML-01**: User can receive earning predictions based on the newly mapped 5 job categories (Ride hailing drivers, Ride hailing instant delivery, Delivery workers in General, On Demand home based services, Remote service providers).
- [ ] **ML-02**: User can expect remote and freelance predictions to be unimpacted by weather and traffic factors.
- [ ] **ML-03**: System serves predictions using a retrained XGBoost model.
- [ ] **ML-04**: System filters job recommendations to only include jobs the user is registered for and has the required skills for.

## Dataset
- [ ] **DATA-01**: System generates an unbiased dataset that maps the specified job platforms into the 5 new job categories.
- [ ] **DATA-02**: System enforces zero impact of weather and traffic on appropriate remote/freelance roles during dataset generation.

## Documentation
- [ ] **DOCS-01**: Developer can read comprehensive docstrings for all functions in the ML engine files.
