    Update DashboardViewModel, ProfileViewModel, and any other ViewModels making API calls.
    - Expose a `StateFlow<String?>` named `errorMessage` (backed by a `MutableStateFlow<String?> _errorMessage`).

    - Wrap all API calls (fetching recommendations, saving skills, etc.) in `try/catch` blocks.
    - Catch `retrofit2.HttpException`, `java.io.IOException`, and generic `Exception`.

  </action>
