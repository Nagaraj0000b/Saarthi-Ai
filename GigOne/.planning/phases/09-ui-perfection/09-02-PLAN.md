# Phase 09 Plan 02: Layout & Aesthetics Polish

## Objective
Fine-tune the Android application's UI to meet high-quality aesthetic and accessibility standards. This includes increasing typography sizes, ensuring high color contrast, implementing haptic feedback, and refining layout spacing as per user requirements.

## Proposed Changes

### 1. Typography & Contrast (Accessibility)
- **File**: `android/app/src/main/java/com/gigone/saarthi/ui/theme/Type.kt` (if it exists) or within Composables.
- **Action**: Increase all instructional and secondary text to a minimum of **14.sp**.
- **Action**: Verify and update `AppColors.TextSecondary` to ensure a 4.5:1 contrast ratio against backgrounds.

### 2. Layout Refinement
- **File**: `android/app/src/main/java/com/gigone/saarthi/ui/screens/DashboardScreen.kt`
- **Action**: Increase vertical spacing between the Top Header and the Recommendation Card from `8.dp` to **16.dp**.

### 3. Interactive Feedback
- **File**: `android/app/src/main/java/com/gigone/saarthi/ui/screens/DashboardScreen.kt`
- **Action**: Integrate `LocalHapticFeedback` to trigger haptic response on Mic release (End of Recording) and Pull-to-Refresh.

### 4. Enhanced Empty States
- **File**: `android/app/src/main/java/com/gigone/saarthi/ui/components/EmptyDashboard.kt` (New or update existing)
- **Action**: Implement a stylized "Empty Dashboard" illustration using Compose-native `Icon` or `Canvas` to encourage user registration.

## Verification Plan

### Automated/Code Verification
- [ ] Inspect modified Composables to ensure `14.sp` and `16.dp` constants are applied.
- [ ] Verify `LocalHapticFeedback.current.performHapticFeedback` is called in the correct event handlers.

### Manual Verification (Instructions)
1. Launch the app and observe the Dashboard.
2. Confirm the gap between header and recommendation card is visibly larger.
3. Verify that the "Hold to Speak" instruction text is legible and larger.
4. Test the mic: release it and feel for the haptic vibration.
5. If no jobs are selected, verify the new stylized empty state is displayed.
