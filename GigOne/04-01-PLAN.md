# Phase 04: Platform Selection Plan

## Objective

Implement the third step of the conversation where the bot extracts the platform (e.g., Uber, Swiggy) the user worked on from their voice input and advances the conversational state.

## Tasks

| Task | Name                            | Description                                                                                                                                           |
| ---- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | **Backend Extraction Endpoint** | Add `extractRawGigData` to `chatV2Controller.js` to expose the existing `extractGigData` service to LangGraph.                                        |
| 2    | **LangGraph Extraction Node**   | Create an `extraction_node` in `nodes.py` that hits the new endpoint and saves `selected_platform` to the state.                                      |
| 3    | **LangGraph Reply Node**        | Create a `reply_node` in `nodes.py` that hits the `raw-reply` endpoint to generate the bot's next question (e.g., "Which platform did you work on?"). |
| 4    | **Graph Routing Updates**       | Update `graph.py` to handle the multi-turn flow (Greeting -> Mood -> Reply -> User Input -> Extraction -> Reply).                                     |
| 5    | **Interactive Testing**         | Create a `test_phase4.py` script that loops to allow a continuous, multi-turn conversation in the terminal.                                           |

## Verification

- [ ] LangGraph correctly extracts "Uber" or "Zomato" when the user mentions it.
- [ ] The bot correctly responds in the chosen language.
- [ ] The `current_step` state successfully transitions from `ask_platform` to `ask_earnings`.

## Handoff Notes

- We are reusing the proven `extractGigData` from `geminiService.js`.
- The empty-input retry safety net implemented in Phase 3 must remain intact.
